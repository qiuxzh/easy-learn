工具开发原则：

- 截断、分页、tsv等AI tool工具通用逻辑，使用[src/main/agent/common-agent/util](src/main/agent/common-agent/util)的工具，禁止service里面实现，service只关心领域
- promptSnippet 字段用于生成系统提示词，汇总成“可用工具”列表，每条是 “工具名：一句话”
- promptGuidelines[] → 系统会把所有工具的 promptGuidelines 拉平成一个全局“使用指引”列表，promptGuidelines。不会和具体工具绑定，模型看到的就是一组全局 bullet
