## 总体架构

agent系统分为三层架构：

底层：model 层。核心：src/main/agent/model/model-runtime.ts
中间：agent 层。核心：src/main/agent/core/agent.ts
上层：agent-session 层。核心：src/main/agent/common-agent/agent-session.ts

## 常见概念

trace：用户发送消息到agent结束运行的过程。等于一个user_prompt + 多个assistants消息
如果中途steering，这个steering消息会新开一个trace
如果中途follow-up，这个follow-up消息会新开一个trace
