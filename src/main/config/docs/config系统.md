# 配置系统

配置系统为桌面应用提供统一的用户配置读写能力。
所有持久化配置保存在同一个 `config.json` 中。
Main 进程持有唯一真实快照，负责加载、默认值补全、校验、持久化和变更通知。
Renderer 只维护配置缓存，不能直接修改磁盘。

Renderer 通过 IPC 查询和提交配置。
查询返回带 `revision` 的完整快照，用于页面初始化与跨窗口同步。
修改使用 `set`、`update`、`remove` 提交局部意图，由 Main 统一合并、校验并原子写入。
成功后 `revision` 递增，Main 和所有 Renderer 同步更新，模型相关配置变化会触发运行时刷新。

配置必须通过统一入口修改，不能绕过服务直接覆盖文件。
未知字段保留，以便兼容未来版本。
配置文件损坏时改名为 `.old.json` 并使用安全默认值。
Renderer 的配置中心只是后端快照的缓存，不是第二真实来源。
