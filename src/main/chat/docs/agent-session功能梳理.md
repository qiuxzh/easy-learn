# 会话组装与运行

会话模块的职责是**组装多种智能体**（对话 agent、coding agent、data agent……），参考 pi：
组装与运行分成两层，品类之间只差一份数据，不靠继承。

## 组装

`createAgentSession()` 是唯一入口。调用方给出会话 id、品类定义与模型运行时，其余按默认行为补齐：

- **模型**：显式指定 → 会话日志里最近使用的模型 → 配置里的默认模型。
- **思考级别**：显式指定，缺省交给内核默认值。它属于单次请求的取值，不落日志。
- **系统提示**：品类定义里的基础提示词，运行时再由调用方追加按运行上下文算出的段落（见 `buildSystemPrompt`）。
- **工具集**：来自品类定义。
- **流式实现**：来自模型运行时。

品类就是一份 `AgentDefinition`：标识 + 基础提示词 + 工具集。新增品类只需再写一份定义，组装与运行两层都不必改动。

## 运行

`AgentSession` 只负责跑：订阅内核事件并落库、发起与中断运行、维护运行期设置。
它拿到的是一份已经装配好的内核 Agent 与会话日志，不做模型选择、不读配置。

## 重建

重建就是组装：**新建与重建走同一条路径**，日志为空即新建，有日志则按日志回放上下文与运行期设置。

因此**会话级**的运行期设置必须落进会话日志，否则重建后无从恢复：新会话在组装时记下初次生效的模型，此后每次变更再各记一条。

思考级别与系统提示不在此列——它们每次运行都由调用方带入或现算，不需要日志回放。

## 暂不涉及

上下文压缩、运行中插话（steering / follow-up）、会话分支。
