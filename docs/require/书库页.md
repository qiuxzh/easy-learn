# 书库（BookShelf）

## 功能概述

书库是用户书籍管理的入口。用户可以浏览已导入的所有书籍、从本地导入新的电子书、以及删除不需要的书籍。

## 书籍浏览

- 以网格卡片形式展示用户导入的所有书籍；
- 每张卡片展示封面、书名和作者；无封面时使用书名的前 8 字符作为默认封面占位；
- 点击卡片进入阅读器。

## 书籍导入

- 提供独立的"导入"入口（网格中第一个固定卡片），点击后弹出系统文件选择框；
- 当前支持 `epub` 格式；
- 导入过程中卡片需要展示加载状态，导入完成后自动刷新列表；
- 导入成功后，源文件需要落地到应用数据目录，封面（如有）独立保存；
- 导入失败时必须给出明确提示，不能静默吞错。

## 书籍删除

- 每张卡片需要提供删除入口，建议通过悬停菜单暴露，避免误操作；
- 点击删除必须经过二次确认（弹窗），提示操作不可恢复；
- 删除需要覆盖三类数据：封面文件、源文件、数据库记录；
- 删除成功后，卡片需要立即从列表移除，不需要等待全量刷新。

## 书籍详情与编辑

- 悬停菜单除删除外，还要提供"详情"入口，打开详情弹窗；
- 详情弹窗展示书名、封面、作者、文件大小、格式、章节数、总页数、导入时间、简介；
- 弹窗内可直接编辑书名、作者，并点击封面从本地选图更换，或移除已有封面；
- 编辑是延迟生效的：关掉弹窗即放弃，只有点击保存才写入数据库与磁盘；
- 书名不允许保存为空；作者允许留空，留空按"无作者"处理；
- 保存成功后书库卡片立即刷新，不需要重新拉取列表。

## 进入阅读器

- 点击书籍卡片后，在 Tab 系统中打开一个阅读器实例；
- 阅读器实例之间相互独立，允许同时打开多本书，也允许同一本书打开多个 Tab；
- 阅读器需要通过参数接收到书名（用于 Tab 标题）和 bookId（用于加载内容）。

## 数据需求

书库需要持久化以下核心信息：

- **书籍身份**：唯一标识（UUID）；
- **展示信息**：书名、作者、封面相对路径、描述；
- **内容规模**：总章节数（导入时从目录解析）；
- **存储信息**：源文件存储文件名（UUID + 扩展名）、格式（当前仅 epub）；
- **时间信息**：导入时间。

## 封面访问

- 有封面的书籍需要能在前端正常展示；
- 封面资源必须通过受限的本地协议访问，防止路径遍历等安全风险；
- 无封面的书籍使用默认占位，不允许渲染失败。
