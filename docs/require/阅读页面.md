# 阅读器（Reader）

## 功能概述

阅读器用于打开并阅读用户导入的电子书（当前仅支持 EPUB），提供目录导航、AI 对话辅助等基础阅读体验。点击书库中任意一本书的卡片会新开一个 reader Tab，多本书可同时打开。

## 整体布局

阅读器页面采用三列布局，列宽可拖动调整：

- **左侧目录栏**：展示书籍目录树，多层嵌套，可展开/折叠。默认隐藏。
- **中间内容区**：渲染书籍正文。最小宽度受限，避免目录和对话同时打开时被压扁。
- **右侧对话栏**：嵌入 AI 对话组件，提供与阅读内容相关的问答能力。默认隐藏。

顶部悬浮一个工具栏，左侧是目录的"显示/隐藏"开关，右侧是对话栏的"显示/隐藏"开关，中间留白用于后续扩展（字号、主题、进度等）。

三列可以同时显示（形成完整阅读 + 目录 + 对话的视图），也可以只保留中间内容。

## 目录

目录数据由前端 BookLoader 在加载书时一次性解析完成。目录树支持多层嵌套，每一层按缩进对齐。

当前阶段目录的展示已实现，但点击章节跳转的交互逻辑尚未实现，等待后续开发。

## 内容渲染

- 内容渲染的具体逻辑（分页、滚动、高亮、选区）由后续接入 foliate-js 的 paginator/overlayer 完成
- 当前位置（CFI 字符串）由 BookViewer 维护
- 翻页接口（navigateToPos）由 BookViewer 注入到 store，供其他组件（如后续的目录跳转）调用

## 加载流程

打开 reader Tab 后，组件挂载时启动异步加载：

1. 通过 bookId 向主进程请求文件路径
2. 渲染端读取 buffer 并喂给 foliate-js 解析
3. 解析得到的 BookEntity 写入 store，加载完成
4. 加载期间显示加载态遮罩，完成后切换为内容区
5. 加载完成时把书名回填到 Tab 标签的标题

## 关闭与清理

reader Tab 关闭时，对应的运行时状态（BookEntity、当前位置、加载的 foliate 句柄）会从 store 中清理，避免内存泄漏。

## 进度持久化

当前阶段阅读进度（当前位置）只保存在内存中，关闭 Tab 后丢失。后续如需跨会话恢复，需引入数据库进度表。

## 数据约束

- reader 类型的 Tab 是多实例：可以同时打开多本书，也可以同时打开同一本书的多个 Tab
- 每个 reader Tab 独立持有运行时状态，互不干扰
- chat 嵌入到阅读器时，每个阅读 Tab 对应一个 Chat 组件实例，多实例间互不干扰
